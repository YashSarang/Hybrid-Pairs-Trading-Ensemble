# Reports Directory

This directory stores all backtest run reports generated by the Pairs Trading application.

## Structure

Each run is saved in a subdirectory named with a timestamp (format: `YYYYMMDD_HHMMSS`).

### Files in Each Run Directory

- **metadata.json**: Run configuration including universe, weights, and parameters
- **metrics.json**: Performance metrics (Gross and Net returns, Sharpe, volatility, etc.)
- **params.json**: Detailed backtest parameters
- **equity_gross.csv**: Gross equity curve (before costs)
- **equity_net.csv**: Net equity curve (after costs)
- **pnl_gross.csv**: Per-period gross P&L
- **pnl_net.csv**: Per-period net P&L
- **turnover.csv**: Per-period turnover (number of position changes)
- **trades.csv**: Complete trade log with timestamps, pairs, and signals

## Usage

Reports are automatically saved when you run a simulation. You can:

1. View reports in the "Reports" page of the application
2. Compare performance with benchmark indices (Nifty, Sensex, etc.)
3. Download individual CSV files for further analysis
4. Delete old reports to save space

## Benchmark Comparison

The Reports page allows you to compare your strategy returns with major Indian indices:

- NIFTY 50
- NIFTY 100
- NIFTY 200
- NIFTY 500
- SENSEX
- NIFTY BANK
- NIFTY IT

Comparison metrics include:

- Excess returns
- Information ratio
- Tracking error
- Side-by-side return charts
